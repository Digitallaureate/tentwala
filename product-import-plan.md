# TentWala Product Import Plan

This sheet is aligned to the current `products` collection shape used in the codebase.

## Recommended import fields

- `id`
- `code`
- `name`
- `slug`
- `item_type`
- `service_group`
- `category_ids`
- `pricing_model`
- `source`
- `is_featured`
- `is_active`
- `sort_order`
- `search_tags`
- `search_text`
- `short_description`

## Notes

- Keep `is_featured` for homepage highlighting because the current UI already uses it.
- You do not need `is_popular` yet unless you want a second manual badge later.
- `search_tags` should stay compact and human-editable.
- `search_text` can be generated from name, group, slug, and tags.

- `wedding-functions`

- `corporate-institutional`
